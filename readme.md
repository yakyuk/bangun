## 🎁 What's Included

Repositori ini mencakup seluruh aset, halaman pemasaran, dan portofolio proyek konstruksi serta fabrikasi container/booth.

### 📌 Key Features

- 🏗️ **Portfolio Showcase:** Untuk menampilkan proyek *jasa tukang*, restorasi, dan pembuatan *booth custom*.
- 📞 **Contact & Order Form:** Memudahkan klien menghubungi atau memesan jasa konstruksi.
- 🔍 **Search Functionality:** Membantu pengunjung mencari artikel tips bangunan atau layanan spesifik.
- 🌑 **Dark Mode Support:** Desain modern dengan opsi mode gelap.
- 📱 **Fully Responsive:** Dioptimalkan secara penuh untuk perangkat mobile dan desktop.
- 📝 **Markdown-Driven Content:** Kelola konten layanan, portofolio, dan blog dengan mudah via file Markdown.

### 📄 Pre-designed Pages

- 🏠 **Homepage:** Halaman utama yang menampilkan ringkasan layanan, keunggulan, dan proyek terbaru.
- 👤 **About Us:** Profil tim, visi, dan misi Yakyuk Bangun.
- 🛠️ **Services:** Detail layanan (Jasa Tukang, Custom Booth Coffee Shop, Fabrikasi Container, dll.).
- 📂 **Portfolio/Gallery:** Galeri transformasi proyek (sebelum & sesudah restorasi/pembangunan).
- 📝 **Blog / Tips & Trick:** Artikel seputar dunia konstruksi dan perawatan bangunan.
- 📞 **Contact:** Formulir kontak dan integrasi peta/lokasi operasional.

### 📦 Tech Stack

- [Hugo (Extended)](https://gohugo.io/)
- [Tailwind CSS v4.0](https://tailwindcss.com/)
- [AutoPrefixer](https://autoprefixer.github.io/)
- [Markdown](https://markdownguide.org/)
- [Prettier](https://prettier.io/)
